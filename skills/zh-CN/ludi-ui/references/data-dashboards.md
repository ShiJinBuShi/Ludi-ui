# 数据后台与看板

## DATA-01 · 筛选与查询意图

**Default（默认）。** 优先外放最有用的筛选，提供易发现的“更多筛选”、已应用数量/摘要、清空/重置。三四个外放条件是布局起点，不是上限。不能只为截图简洁隐藏关键或常组合使用的条件。

根据实测延迟、查询成本与用户组合字段的方式选择即时或统一查询，不按固定数据行数决定。统一查询时区分**草稿条件**与**已应用条件**；结果、计数、分页、导出和 URL 状态对应同一已应用快照。即时查询按需要对文字输入防抖，拒绝旧响应覆盖；合适时刷新期间保留可用的旧结果。

**验证：** 连改多个草稿条件不提前查询；应用一次使用一致快照；重置、分页、前进/返回、慢/乱序响应和失败请求行为一致。

## DATA-02 · 时间属于数据契约

**Contract（契约）。** 显示实际区间和报表时区。明确“近 7 天”包含今天、指完整自然日，还是滚动 168 小时。保留服务的起止包含关系；`[start, end)` 常便于避免重复边界，但不得强加给不同契约的 API。跨夏令时的自然日不能简单按固定毫秒数相减。

提供有用的快捷范围及可访问的输入/日历；只有空间合适才默认双月。不可选日期按实际能力限制并解释，不编造 90 天后端上限。同期对比需受支持且正确对齐的区间、明确标签和非颜色区分，不是所有图表的必备功能。

**验证：** 零点、跨月/年、适用时的时区和夏令时、末日包含关系、无效区间、快捷范围，以及可见标签与请求参数一致。

## DATA-03 · 层级与选择压缩

**Contract（契约）。** 语义上的选中集合独立于压缩标签。父级全选/部分选中可显示“研发部 · 全选”“19/20”，但不改变提交 ID。明确父级选择代表当前子项，还是动态包括未来新增子项；服务端分页或未完整加载的树不能假设子项已全部在本地。

明确本页全选还是全部匹配结果、禁用/无权项、未知总数、清除分组及跨页选择。聚焦/点击可查看并移除单项。单行加 `+N` 是可选密度方案，缩放与翻译下仍需可用。

**验证：** 取消一个子项、树未加载完整、数据/权限变化、搜索、分组清除、重开，以及聚合前后请求载荷中的选中集合完全一致。

## DATA-04 · 看板应回答问题

**Default（默认）。** 先明确用户决策，再选择指标与图表。少量核心指标、走势/对比、更新时点和口径通常有帮助。不得因为布局留了位置就编造 KPI、趋势、百分比、时间戳或提升承诺。原笔记的 58%/40% 改善不构成本产品证据。

数据契约支持时才做联动/下钻：显示活动上下文、面包屑/返回和重置，相关面板使用同一状态源。区分加载、真实零值、空、过期、部分成功和错误。关键图表信息提供文字/表格替代。

**验证：** 界面能回答目标问题；联动面板条件一致；返回上级恢复上下文；过期/部分结果如实标记。

## DATA-05 · 导出与行动衔接

**Contract（契约）。** 只在用户要求或现有能力支持时加入导出。权限由服务端执行，隐藏按钮不是权限边界。导出使用已应用筛选、报表时区、排序及明确的当前页/全部结果范围。异步导出展示等待/完成/失败，避免重复任务。明确旧结果的导出行为，不静默改用不同条件。

**验证：** 请求参数与可见已应用状态一致，覆盖权限拒绝、空导出、失败/重试、文件名与内容格式。遵循项目既有的表格公式注入处理，不临时自创转换方案。
