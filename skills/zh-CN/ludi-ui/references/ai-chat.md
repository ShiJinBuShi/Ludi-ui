# AI 聊天与动态工作区

## AI-01 · 输入法安全提交

**Contract（契约）。** 先检查项目的发送/换行快捷键。跟踪 `compositionstart`/`compositionend`，并检查键盘事件 `isComposing`，或框架原生事件。提交输入法候选的 Enter 不得发送消息。尊重修饰键、重复 keydown、空值/禁用/等待状态及独立发送按钮。按钮、快捷键、表单共用单一提交路径，避免重复发送。

部分浏览器/输入法事件顺序可能需要定向兼容保护，先观察支持环境的实际序列。已弃用的 keyCode 229 只能作为局部回退，不是主要模型。不得统一加入 composition 后 500ms 冷却期，它可能吞掉用户下一次有意的 Enter。合成事件测试能验证逻辑，不能证明真实浏览器/输入法的事件顺序。

**验证：** 适用时使用真实中文/日文输入法，覆盖候选确认 Enter、紧接着有意发送的 Enter、Shift+Enter/项目换行约定、长按 Enter、按钮发送与无重复提交。没有真实输入法/Safari 条件时明确说明。[UI Events 组合输入语义](https://www.w3.org/TR/uievents/#events-compositionevents)和 [isComposing 文档](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/isComposing)用于理解事件模型，不支持统一防抖时长。

## AI-02 · 阅读者控制跟随

**Contract（契约）。** 将“跟随最新输出”建模为明确状态。仅在阅读者靠近末尾或主动要求最新时跟随；用户主动离开底部就暂停。新 token、图片、代码块、尺寸变化不能把阅读者从历史内容拉走。回到底部或点击“跳至最新”可恢复；在底部的普通滚轮操作无需永久关闭跟随。

使用底部哨兵或带容差的距离判断，不依赖精确相等。一行/三行是起始经验，按实际密度和视口选阈值。暂停期间展示键盘/触屏可用的最新按钮或未读提示。合并滚动工作，不逐 token 平滑滚动；尊重减少动态效果。

**验证：** 流式输出 → 上滚 → 继续输出 → 保持阅读位置 → 跳至最新 → 恢复跟随，同时覆盖异步媒体和输入区尺寸变化。

## AI-03 · 流式输出、恢复与渲染成本

**Contract（契约）。** 保持消息 ID、文字选择、复制、Markdown/代码结构与辅助技术阅读能力。合并渲染工作，不对无上限长输出逐字符创建 DOM/计时器。未闭合标记不得破坏结构；不可信内容按项目既有净化管线渲染。

区分等待、输出中、已停止、失败和完成。按生命周期终止/清理过期流。重试不静默重复消息，不编造服务不支持的断点续传；播报有意义的阶段，不逐 token 播报。

**验证：** 长输出、代码围栏跨 chunk、失败/停止/重试、离开页面、复制/选择，以及计时器/监听器不持续增长。短暂 chunk 渐显属于可选视觉优化，应在减少动态效果时关闭或简化。

## AI-04 · 可调整分屏

**Default（默认）。** 为面板设有用的最小宽度，无法同时容纳时切换为标签或上下布局。拖动时使用 pointer capture，必要时临时屏蔽 iframe 内交互。释放、取消、失焦/卸载时移除遮罩、监听器及光标覆盖。分隔条支持键盘，提供名称、方向、当前值和边界；必要时用按钮提供等价的收起/恢复。

Esc 可取消本轮拖动并恢复起始尺寸。双击重置和低于 20% 自动收起均为可选惯例，采用产品有用的默认值/最小宽度；收起后保留可见的恢复入口。

**验证：** 穿过 iframe、指针取消、键盘调整、窄屏、重置/收起/恢复及面板消失时的焦点。[APG Window Splitter](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/)是有用的工作中指南，实现自定义模式时核对其当前状态。

## AI-05 · 附件名称与元数据

**Default（默认）。** 长文件名可用弹性主体和不收缩的后缀保留格式信息。通过可访问名称及聚焦/点击详情提供全名，不只在 hover 时显示。对截断的 flex 子项设置 `min-width: 0`。复合后缀按产品需求识别，展示后缀不等于 MIME/安全校验。

**验证：** 无后缀、`.env`、复合后缀、Unicode/RTL、重名、极窄容器，以及完整可访问名称不改变上传载荷。
