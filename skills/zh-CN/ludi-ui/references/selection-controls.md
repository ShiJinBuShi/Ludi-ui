# 选择控件

## SEL-01 · 值还是命令

**Contract（契约）。** Select/combobox 选择一个保留显示并参与表单/筛选状态的值；菜单提供导出、重命名、删除等动作。按语义选型，不按触发器有无边框判断。区分值、显示标签、禁用状态与提交 ID；译文不是标识符。不得为了复用样式，把危险命令塞入 Select 选项。

**验证：** 选择只更新目标字段，命令只执行对应动作；请求载荷不变，不意外提交或导航。

## SEL-02 · 合理外放选项

**Default（默认）。** 少量、短小、可比较的选项可用 Radio 或分段控件。立即生效的布尔设置可用 Switch；随表单提交的布尔值或协议勾选用 Checkbox。高密度表格或原生移动端中，两个选项使用 Select 也可能合理。数量、标签长度、空间、频率和一致性共同决定，不把“两个选项禁用 Select”视为通则。

用户熟悉的数据使用合适的输入方式。电话号码和标识符是字符串，可能带前导零或 `+`，应使用 text/tel 等类型及合适的输入提示，不使用数字微调框。日期可直接输入并辅以日历，但保留本地化和校验要求。

**验证：** 用户知道何时生效；控件接受真实有效的数据。

## SEL-03 · 长列表与远程搜索

**Default（默认）。** 扫描困难时提供搜索/键入定位；超过约十项是复查信号，不是标准规定的分界。面板高度受可用视口约束，内部可滚动。优先使用定位基础组件的翻转/避让能力，不硬编码统一向上或向下。264px 最大高度可以是起始 token，不能保证面板一定放得下。

远程搜索需有等待、空、错和重试状态；取消过期任务或拒绝旧响应覆盖。当前结果不包含已选项时仍保留选中值。确有必要才做虚拟化，并保持活动选项的无障碍语义。

**验证：** 在适用的视口边缘完成输入、键盘移动、选择、清空、重开，以及慢请求/乱序响应的恢复。

## SEL-04 · 可访问交互

**Contract（契约）。** 原生 Select 足够时优先使用；自定义控件遵循相应 combobox/listbox/menu 模式。可访问名称与当前值分开，维护展开状态、面板关联、活动选项和选中状态。Esc 安全退出选项探索。应用快捷键不得拦截搜索框输入。

**验证：** 键盘完成流程，检查组件库最终生成的角色和状态。确需自定义 combobox 时查阅 [APG 指南](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)。

## SEL-05 · 多选展示

**Default（默认）。** 空间有限时用分组/计数和 `+N` 压缩标签，保持真实选中 ID 不变。通过聚焦/点击提供完整选项查看、单项移除和清空，不能只有悬停名单。不得为了单行外观牺牲查看和编辑能力。涉及树选择或“全部结果”时，另读[数据后台](data-dashboards.md)的 DATA-03。

**验证：** 长标签、部分选中、分组折叠、禁用项和移动端移除都不会意外改变选中集合。
